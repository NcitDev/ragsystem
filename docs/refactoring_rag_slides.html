The Taxonomy

Seven tools. Four phases. One matrix.

The Seven Tools

What each one actually does

ToolSubstrateBest AtWeakness
grepPlain textExact-symbol enumeration, magic numbers, literalsNo semantics, no scope
LSPSymbol table + typesRename · find-refs · call-hierarchyStops at the symbol boundary
ASTSyntax treeStructural patterns: nesting, signature shapeNo cross-file reasoning
vRAGDense embeddingsSemantic similarity, "code like this"Top-k cutoff · not exhaustive
mRAGVectors + payload filtersExhaustive filtered lookups: is_suspend, complexity_cyclomaticOnly as smart as the metadata
gRAGCall / dep graphFan-in/out, centrality, Feature EnvyNeeds accurate graph build
askRAGRetrieved chunks + LLMSynthesis, design calls, codegenSlow, costs tokens, can hallucinate

Decomposing Every Refactoring

D · P · E · V

  • D — Detection
    "Where does this smell live?"
  • P — Planning
    "What sites are affected if I change it?"
  • E — Execution
    "Rewrite tokens safely."
  • V — Verification
    "Are call sites, types, tests consistent?"
refactoring(query) { phase_D: find_candidates() phase_P: trace_impact() phase_E: rewrite() phase_V: prove_safe() } // each phase picks // a different tool

Bucket E

askRAG required

Cannot reduce to a query. Needs synthesis — model reads code and reasons.

  • Substitute Algorithm (LLM writes replacement)
  • Extract Class / Subclass / Superclass / Interface execution
  • Form Template Method — identify variant points
  • Introduce Null Object — design the null class
  • Strategy / State application — design call
  • Memento detection in legacy — semantic concept
# every E task retrieve(query) → top_k chunks prompt(system, chunks, question) → qwen3:8b ↓ grounded answer + citations [N] # 10–30s · costs tokens # only fire when needed

grep approach

Finds the text.
Misses the intent.

shell# find candidates for Pull Up Method $ rg 'fun \w+\(.*\): \w+ \{' \ -t kotlin | awk '...' # now diff every pair? manually? # semantic dupes are invisible # to text search

RAG approach

One metadata query.
Exhaustive.

cli# precomputed at index time $ rag list near_duplicate_method_hash \ --group-by hash --min-count 2 # groups semantically-equivalent # methods regardless of names, # whitespace, identifier renames

Daemon Router

The Decision Rule

router.pydef route(query: str) -> Plan: smell = classify(query) # refactoring intent if smell.bucket == "C": # grep/LSP/AST wins outright return Plan(skip_rag=True, hint="use rg / LSP rename") if smell.bucket == "A": # semantic-only smells return Plan(retrieve="mRAG+gRAG", synthesize="askRAG") if smell.bucket == "B": # filter, then hand to LSP return Plan(retrieve="mRAG", execute="LSP code-action") if smell.bucket == "D": # graph signatures return Plan(retrieve="gRAG", traverse="call-graph") if smell.bucket == "E": # synthesis required return Plan(retrieve="mRAG", synthesize="askRAG")
